# 🏧 ATM Management System - C++

A beginner-friendly **ATM Management System built in C++** to practice programming fundamentals, functions, loops, conditional statements, and menu-driven programs.

## 📌 Features

* 🔐 PIN-based authentication
* 🔢 Maximum 3 PIN attempts
* 💰 Check account balance
* 💸 Withdraw cash
* 💵 Deposit cash
* 🔄 Change PIN
* ❌ Exit option
* ⚠️ Input validation for withdrawals and deposits
* 📋 Menu-driven interface

## 🛠️ Concepts Used

This project currently uses:

* C++
* Functions
* `if-else`
* `for` loop
* `do-while` loop
* `switch-case`
* Variables
* Basic input/output using `cin` and `cout`
* Basic input validation

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/ekkux27/ATM-Management-System-CPP.git
```

### 2. Open the project folder

```bash
cd ATM-Management-System-CPP
```

### 3. Compile the program

```bash
g++ ATM.cpp -o ATM
```

### 4. Run the program

Windows:

```bash
.\ATM.exe
```
